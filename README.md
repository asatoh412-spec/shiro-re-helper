# 城プロRE 編成補助

御城プロジェクト:RE の編成を考えるための非公式の個人制作ツールです。ブラウザ／スマホのホーム画面から使えます（PWA）。

- 8体までの城娘を選ぶと、各城娘に実際にかかるバフ、敵へのデバフ、計略オン/オフでの変化、足りない効果とその候補を表示します。
- データは [城プロRE攻略wiki](https://scre.swiki.jp/) の公開情報をもとにした数値と効果の要約です。特技・計略などの説明文そのものは含めていません。原文はwikiを参照してください。
- 効果は文章から自動で読み取っているため、読み違いがあり得ます。
- ゲームの権利は運営（DMM GAMES ほか）に帰属します。このツールはゲームに接続せず、運営とは無関係です。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（`tools/build.py` が生成） |
| `data.json` | 城娘データ（週次で自動更新） |
| `sw.js` / `manifest.webmanifest` / `icon-*.png` | PWA（オフライン動作・ホーム画面追加） |
| `tools/build.py` | wikiの取得とこれらのファイルの生成（`python3 -I tools/build.py --pwa .`、標準ライブラリのみ） |

スクショ読み取りは任意機能で、設定にAnthropic APIキーを入れた場合だけ使えます。キーはブラウザ内にだけ保存されます。
