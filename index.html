城プロRE 編成補助

空き枠をタップすると城娘を探せます。名前をタップすると一覧のその城娘へ移動します。

まとめて読み込む

アイコンの見方

茶色・青のタグが計算に使っている効果、緑のタグが隠密無効や足止め数などの特殊効果です（点線枠は「〜する度に」などの条件付きで、上限値で計算）。

全員が互いの射程内にいる前提で、計算式どおり有効になるものだけを表示します。固定値は合計だけを出し、「内訳」で提供元を見られます。実数値は初期値（Lv・装備なし、最大化の巨大化補正あり）での目安です。

計算の設定

スクショ読み取り（任意）

キーはこの端末のブラウザにだけ保存され、スクショを読み取るときにAnthropicへ直接送られます（このツールの運営側には送られません）。キーは専用のものを作り、Consoleで使用量を確認できる状態にしておくのがおすすめです。

データ管理

効果の読み違いを直したいときは「JSONを編集」で該当城娘の effects を書き換えてください。編集したデータはこのブラウザに保存されます。

データ: 城プロRE攻略wiki（scre.swiki.jp）より（2026-11-10 取得）。特技・計略などは効果の要約で、原文はwikiを参照してください。効果は自動で読み取ったもので、読み違いがあり得ます。非公式の個人制作ツールです。

計算ルール

  • 同じ種類の割合バフ/デバフは、一番高いものだけ有効（説明文に「重複」とあるものは加算）。固定値は全て加算。
  • 編成特技・所持特技・特技/計略は別系統なので、割合バフは系統ごとに掛け算で重なる。
  • 攻撃（ステータス） = (((初期攻撃×(1+編成%)＋編成固定)×(1+所持%)＋所持固定)×巨大化補正) ×(1+特技計略%)＋固定値＋変換・鼓舞。乗算ごとに端数切り捨て。
  • 攻撃値 = 攻撃（ステータス） × 攻撃値倍率。攻撃値倍率は計略の「攻撃のN倍のダメージ」、「与えるダメージがN倍」、特攻（弓の対飛行1.5倍、「飛行敵に対して攻撃が2倍」など）、直撃ボーナス（大砲・軍船は+50%）、飛行敵への近接攻撃半減・妖怪への物理攻撃半減で、全て掛け算で重なる（特技と計略の「与えるダメージ」同士も掛け算）。特攻は同じ種類の中では一番高いものだけ。敵の種類は上の設定で選ぶ。
  • ダメージ = (攻撃値 − 敵防御)（最低20） ×(1+与ダメ増)×(1+敵の被ダメ増)。「与ダメージ+N%」は特技・計略の中では一番高いものだけ。法術・鈴・杖・祓串は防御無視で、妖怪に半減されない。
  • 「特殊攻撃で与えるダメージ」は通常攻撃の1撃には含めず、「計略で/計略中に与えるダメージ」はその城娘の計略をオンにしたときだけ含める。
  • 敵防御 = (防御×(1−特技計略の防御低下%) − 固定値低下) ×(1−防御無視%)。防御無視は特技計略の最大値＋鎌の武器種特性を加算。
  • 変換バフ（「攻撃に防御の50%の値を加算」）と鼓舞バフ（「自身の攻撃の35%の値を射程内の城娘に加算」）は、割合・固定値の後に加算。加算元は他のバフ適用後の値。鼓舞は提供者自身には掛からないものとして計算。
  • 攻撃速度・隙短縮は系統ごとに乗算。射程の位置関係は考慮せず、「射程内」の効果は全員に届くものとして扱う。
  • 能力値は改壱・改弐のある城娘は一番上の段階の初期値。特殊能力は「特殊」をオンにしたときだけ計算に入る。
  • 出典: wiki「検証」ページの「ステータス計算式」「ダメージ計算式」「特技・計略・武器の重複、競合」。地形・装備・武器効果は未反映。
  • 「巨大化する度に」の効果は最大化した値（☆1〜2は3回、☆3〜5は4回、☆6〜7は5回分）で計算し、「最大化時」の効果も含めています。能力値には最大化したときの巨大化補正（単属性は1回につき耐久・防御+22%、攻撃+18%、射程+16%、回復+12%、複合属性は+20%・+16%・+16%・+10%）を、編成・所持特技の後、特技・計略の前に掛けています。
  • 武器種・近遠のアイコンはこのツール用に作ったもので、ゲームの画像ではありません。

ユニットデータ（JSON）

データ形式の説明 
配列の各要素が1体です。
{ "id": "図鑑No.", "name": "名前", "rarity": 7, "kai": "壱",
  "attr": ["平山","水"], "weapon": "弓", "range": "遠",   // range は 近 / 遠 / 両
  "hp": 1000, "atk": 200, "def": 80, "rng": 260, "heal": 10, // 初期値
  "skill":     { "text": "特技の説明", "effects": [ ... ] },
  "strategy":  { "text": "計略の説明", "effects": [ ... ] },
  "formation": { "text": "編成特技", "effects": [ ... ] },
  "held":      { "text": "所持特技", "effects": [ ... ] },
  "specialAttack": { "text": "大破特技・特殊攻撃" },
  "specialAbility": { "text": "特殊能力", "effects": [ ... ] } }
各ブロックの "tags": [{ "tag": "足止め数増加", "value": 2 }] は隠密無効などの特殊効果です。
effects の各要素: { "type": 種類, "value": 数値, "target": 対象, "stack": 重複するなら true, "cond": 条件付きなら true }
種類: EFFECT_LIST
対象: self(自身) / all(全城娘) / inrange(射程内) / near(近接) / far(遠隔) / target(計略の対象) / enemy(敵)
      / weapon:弓|鉄砲 / attr:水 / other:地域名など(計算対象外)
